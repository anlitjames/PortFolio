# Anlit James — Software Engineer Portfolio Website

A modern, high-performance, dark-themed developer portfolio website for **Anlit James**, Software Engineer with 3+ years of enterprise experience in Angular, .NET Core Web API, C#, Entity Framework Core, and MS SQL Server.

## 🚀 Key Highlights & Sections

- **Header & Navigation**: Sticky navbar with glassmorphism blur, responsive mobile hamburger navigation drawer, and active scroll-spy link tracking.
- **Hero Section**: Strong introduction, primary stack highlights (`Angular` • `.NET Core` • `C#` • `SQL Server` • `TypeScript`), quick CTAs, and an interactive dual-tab Code Editor (`BookingController.cs` & `flight-search.component.ts`).
- **About & Capabilities**: Professional background, 6 key highlights, and 4 dedicated capability cards (Frontend, Backend, Database, Authentication & Integration).
- **Technical Skills**: Structured, categorized tech badges across Languages, Frontend, Backend, Database & ORM, Authentication, Tools, and Engineering Concepts.
- **Work Experience**: Vertical interactive timeline featuring roles at **Penguin Data Centre Pvt Ltd**, **AppRocker Technologies**, and **Luminar Technolab**.
- **Featured Projects**: Detailed cards for **PenAir** (Travel Agency Management), **PenIBE** (Flight Booking Engine), and **EventZet** (Event Management System), with interactive "View Details" modals providing architecture flows, provider integrations (Amadeus, Sabre, Air Arabia, Dreamlake, Lime), and concrete development contributions.
- **Full-Stack Architecture**: Visual pipeline illustrating how Angular connects via REST API to .NET Core Web API, Entity Framework Core, and MS SQL Server.
- **Education**: B.Sc. Computer Science from University of Calicut (2019 – 2022).
- **Contact & Resume Download**: Quick copy-to-clipboard for Email & Phone, contact form with real-time validation, and print/download CV actions.

## 🛠️ Local Preview

You can open `index.html` directly in any modern browser, or serve it using any static HTTP server:

```powershell
# Using Python
python -m http.server 8080

# Or using npx serve
npx serve .
```

Then visit `http://localhost:8080`.
